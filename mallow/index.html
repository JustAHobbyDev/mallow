mallow.css

A tiny, soft CSS framework.

Mallow gives semantic HTML a quiet dark interface, then adds a handful of layout primitives for the places HTML needs a little help.

View specimen

Semantic HTML

Most pages shouldn't require a pile of component classes. Text, links, lists, forms, tables, quotes, and code should look considered before you add a single class.

Typography

Mallow favors restrained hierarchy and comfortable reading measure. Here is an ordinary link, some inline code, and muted text.

  • Semantic first
  • Dark by default
  • Small vocabulary
